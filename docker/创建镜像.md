# 创建docker镜像

1. 使用空的镜像源
   1. 拉取`alpine`镜像，`docker pull alpine`
   2. 查询版本号`docker run --rm alpine cat /etc/alpine-release`
   3. 例如查询到为`3.24.1`，可使用`3.24`锁定小版本更新
2. 创建空的镜像源
   1. 创建文件夹`test`
   2. 在`test`文件夹内创建文件`Dockerfile`，并写入以下内容

```sh
# 指定基础镜像和版本
FROM alpine:3.24
# 指定工作目录
WORKDIR /app
# 常驻命令，休眠永久不退出，方便调试
CMD ["tail", "-f", "/dev/null"]
```

3. 进入`test`文件夹，打包镜像`docker build -t test-image:dev .`
   - `test-image`为镜像名
   - `dev`为版本号
   - 尾部的`.`表示当前目录
   - 可以使用无缓存构建`docker build --no-cache -t test-image:dev .`

4. 查看打包好的镜像`docker images`，`test-image:dev`为镜像名和版本号
5. 启用临时容器并进入内部`docker run -it --rm test-image:dev sh`(不能使用`bash`)
6. 创建容器`docker run -d --name test-image test-image:dev`
7. 进入容器内部`docker exec -it test-image sh`
8. 更新软件包`apk update`
9. 安装软件`apk add openvpn`(可以使用无缓存安装`apk add --no-cache openvpn`)
10. 创建配置文件夹`mkdir -p /etc/openvpn/server/`
11. 为以下配置

```sh
# 指定基础镜像和版本
FROM alpine:3.24
# 提前替换国内源，解决apk下载慢
RUN sed -i 's/dl-cdn.alpinelinux.org/mirrors.aliyun.com/g' /etc/apk/repositories
# 安装软件并删除缓存
RUN apk update \
    && apk add --no-cache \
    openvpn \
    openssl \
    && rm -rf /var/cache/apk/*
# 创建配置文件夹
RUN mkdir -p /etc/openvpn/server
# 指定工作目录
WORKDIR /etc/openvpn
# 常驻命令，休眠永久不退出，方便调试
CMD ["tail", "-f", "/dev/null"]
```

12. 创建配置文件夹`mkdir -p /docker/openvpn/conf`并把配置文件移入
13. 使用以下命令创建容器

```sh
docker run -d --name test-image \
 -v /docker/openvpn/conf:/etc/openvpn/server \
 test-image:dev
```
